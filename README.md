# ✨ Where Winds Meet (WWM) Text Color Picker & Formatter ✨

An interactive, custom web tool designed to format colored text for **Where Winds Meet (WWM)**. Select individual letters or entire lines, choose colors or gradient presets, and generate ready-to-copy code formatted for in-game chat or profiles.

---

## 🌟 Features

- **🎨 Dynamic Color Picker:** Custom canvas saturation/value picker with smooth HUE slider and modern circular thumb control.
- **🌈 Multi-Color & Gradients:** Apply custom colors to individual highlighted characters or use built-in multi-color gradients for full sentences.
- **📱 Responsive Layout:** Wide horizontal multi-column layout for PC desktops and single-column layout for mobile devices.
- **📋 One-Click Copy:** Easily preview formatted output and copy generated code snippets directly to your clipboard.
- **⏰ Recent & Preset Colors:** Quick-access color swatches and preset palettes inspired by WWM aesthetic themes.

## 🛠️ How to Use

1. **Enter Text:** Type or paste your message into the **Input Text** box.
2. **Apply Colors:**
   - **Single Color:** Highlight specific letters/words in the text area, pick a color using the canvas/slider, and click **✨ Apply to Selected**.
   - **Gradients:** Click any gradient option (like *Sunset*, *Aurora*, or *Sakura*) to color the entire string smoothly.
3. **Copy Code:** Click the **Copy ✂️** button on the **Formatted Code Output** card.
4. **Paste In-Game:** Paste your output code directly into *Where Winds Meet*!
